# Monster Collection (веб-застосунок / PWA)

Колекція смаків Monster: порожні слоти з підписами → фото банки → слот заповнюється.

## Публікація на GitHub Pages
1. Залий всі файли в **корінь** репозиторію (index.html має лежати зверху, не в підпапці).
2. Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
3. Через 1–2 хв зверху сторінки Pages з'явиться посилання: `https://ТВІЙ_НІК.github.io/НАЗВА_РЕПО/`

## Як встановити на iPhone
Відкрити посилання в **Safari** → кнопка «Поділитися» → «На початковий екран» → «Додати».
Фото зберігаються на самому телефоні (кожен користувач має свою колекцію).
